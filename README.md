# CPP DX11 Jungle GTL

Native snapshot repository for the Week01 through Week14 engine projects.

This repository is flattened from the original weekly project repositories. Build outputs, local IDE caches, generated releases, and resource folders are intentionally excluded from version control.

## Layout

- `Week01/` through `Week14/`: weekly engine work

## Excluded

- `Release/`
- `Resource/` and `Resources/`
- downloaded/reference folders such as `Others/`, `Clone/`, and `Videos/`
- local root asset/document folders outside `Week01/` through `Week14/`
- Visual Studio state such as `.vs/`
- Build/debug outputs such as `Build/`, `Bin/`, `Debug/`, `Intermediate/`, `Saved/`, and crash dumps
- Archives and diagnostic captures

Large source assets that remain tracked use Git LFS.
