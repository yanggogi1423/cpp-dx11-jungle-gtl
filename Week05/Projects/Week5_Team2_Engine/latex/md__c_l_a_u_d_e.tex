DirectX 11 3D scene editor engine built with C++ and Im\+Gui. Actor/\+\+Component architecture with WYSIWYG editing, raycasting object selection, multi-\/scene management, and JSON serialization. Includes a standalone OBJ mesh viewer mode ({\ttfamily Obj\+View\+Debug} build) for previewing static meshes.

{\bfseries{Week 5 focus:\+}} High-\/performance rendering competition — render 50,000 {\ttfamily Static\+Mesh\+Component}s (50×50×20 grid) as fast as possible. Key constraint:\+ one Draw Call per Static\+Mesh (no {\ttfamily Draw\+Instanced}/\+{\ttfamily Draw\+Indexed\+Instanced}). Optimization targets:\+ Frustum Culling, Scene Graph (BVH/\+\+Octree/\+\+K-\/d tree), SIMD. Custom runtime type information using {\ttfamily DECLARE\+\_\+\+CLASS} /\+ {\ttfamily DEFINE\+\_\+\+CLASS} macros that build {\ttfamily FType\+Info} chains. Supports {\ttfamily IsA\texorpdfstring{$<$}{<}T\texorpdfstring{$>$}{>}()} and {\ttfamily Cast\texorpdfstring{$<$}{<}T\texorpdfstring{$>$}{>}()}. {\ttfamily UObject\+Manager} singleton handles lifecycle and auto-\/naming ({\ttfamily Class\+Name\+\_\+N}). {\ttfamily FName} is a pooled, case-\/insensitive string identifier.\hypertarget{md__c_l_a_u_d_e_autotoc_md5}{}\doxysubsection{\texorpdfstring{Rendering Pipeline}{Rendering Pipeline}}\label{md__c_l_a_u_d_e_autotoc_md5}
Multi-\/pass command buffer pattern:\+ {\ttfamily Render\+Collector} (scene traversal → {\ttfamily FRender\+Command}) → {\ttfamily Render\+Bus} (per-\/pass queuing) → {\ttfamily Renderer} (GPU submission via {\ttfamily FPass\+Render\+State} lookup tables).

Render pass order:\+ Opaque → Font → Sub\+UV → Translucent → Stencil\+Mask → Outline → Editor → Grid → Depth\+Less.

Adding a new render pass = one entry in the {\ttfamily FPass\+Render\+State} table. Batchers (Line, Font, Sub\+UV) own their shaders and are flushed by the Renderer.\hypertarget{md__c_l_a_u_d_e_autotoc_md6}{}\doxysubsection{\texorpdfstring{Editor}{Editor}}\label{md__c_l_a_u_d_e_autotoc_md6}

Competition constraints:\+
\begin{DoxyItemize}
\item {\bfseries{No Instanced Rendering}} — {\ttfamily Draw\+Instanced} /\+ {\ttfamily Draw\+Indexed\+Instanced} are forbidden; each {\ttfamily Static\+Mesh} issues exactly one Draw Call.
\item {\bfseries{Real-\/time only}} — pre-\/caching results when the camera is stationary is not allowed. Objects may move in/\+out of view at any time.
\item Standard scene ({\ttfamily Default\+Scene.\+zip}) and mesh dataset ({\ttfamily Jungle\+Apples.\+zip}) are fixed; camera info, object count, and meshes may vary between teams at judging time.
\item Performance measured on Alienware m15 R5 (RTX 3070). Winner ranked by FPS score + Picking score (lower ms = better).
\end{DoxyItemize}

Key optimization techniques in scope:\+
\begin{DoxyItemize}
\item {\bfseries{Frustum Culling}} — skip Draw Calls for meshes outside the view frustum.
\item {\bfseries{Scene Graph /\+ Spatial partitioning}} — BVH, Octree, or K-\/d tree to accelerate frustum and ray-\/cast queries.
\item {\bfseries{SIMD}} — SSE2/\+\+AVX for math-\/heavy culling loops ({\ttfamily \+\_\+\+\_\+m128}, aligned allocations).
\item {\bfseries{Render State sorting}} — minimize redundant state changes between Draw Calls.
\end{DoxyItemize}
