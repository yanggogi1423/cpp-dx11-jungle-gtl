-> Main만 별도의 Scene으로 구성 (연출용)
-> Loading은 Game Scene의 로딩을 티 안나게 하기 위해 위에 Overlay로 깔아둠
-> GameOver도 Game Scene에 Overlay로 구성

-> Loading이나 Game Over는 Game Tick을 멈춰야 하기 때문에 UI에서 Game Tick에 따라갈지 별도의 Tick을 따라가게 할지 설정 가능하게 해야 함(Animation은 DeltaTime을 고려해야하기 때문임)

-> 넘겨줄 데이터같은 것들이 없고, GeneralManager의 StartState가 있기 때문에 Scene 분리 결정
-> 단, Lua Tick 중단 등의 안정성때문에 한 프레임 뒤에 Deferred로 Scene 교체
