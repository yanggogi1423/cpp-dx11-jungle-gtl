-> 일단 기본적으로 R Channel 32bit만 사용한다는 가정하에 짬 이후에 PCF, VSM, ESM 등을 모두 고려해야함

[Global Light - Directional Light]
사용할 자료구조 : Texture2DArray[5] -> [0] : PSM 사용, [1~4] : CSM 사용
Default Resolution : 1024*1024 (CSM), 2048*2048 (PSM)
Max Resolution : 2048*2048 (CSM), 4096*4096(PSM)
-> 대략 통합 메모리 사용으로 Default의 경우 대략 17MB, Max의 경우 67MB (단일 RTV만 고려)
-> 또한 PSM, CSM은 같이 사용할 일이 없는 모드 선택이므로, 사용하지 않는 모드의 Texture의 경우 할당을 해제하는 정책을 생각하고 있음

[Local Light - Spot, Point]
사용할 자료구조 : 단일 Atlas texture
Light View 당 Default Resolution : 512*512
Max Resolution : 1024*1024
Atlas 크기 : 4096*4096 (대략 67MB)

[Atlas 정책 기준]
- 카메라(Vector 및 Distance)로 중요한 Light 선별 (일종의 LOD)
- Intensity를 고려
- Atlas의 경우 Fall back 처리 필요 (아예 Texture를 생성하지 않거나, 작은 사이즈라도 줘야함)
- 이를 관리할 자료구조 (Quad Tree?)
- Resolution Scale을 float로 주고 있기 때문에 이를 그대로 반영할 것인지, 아니면 2의 승수로 자를 것인지에 대해서 고민
